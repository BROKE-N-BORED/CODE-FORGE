# Security

## Reporting a problem

If you find a security problem in Code Forge, email
broke.n.bored.studio@gmail.com with what you found, how to reproduce it,
and what you think it exposes. Do not open a public issue for a security
problem — give it time to be fixed first.

## What is supported

The current build on the main branch is the supported version. Older
releases are not patched.

## What Forge does with your data

Forge runs on your own machine. Your provider keys live in an encrypted
vault on your machine, never in plain text. Conversations are stored on
your machine. Nothing is sent anywhere unless you send it — local turns
never leave the machine, and provider turns go only to the provider you
chose.
